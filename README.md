# BOSS'boss · 求职招呼词生成助手

嵌入 BOSS 直聘网页版的 AI 求职助手。在职位详情页一键生成“顾问级岗位分析 + 个性化招呼词”，人工审阅后填入聊天框，全程零界面切换。

## ✨ 核心特性
- **安全无风险**：绝不自动发送、绝不自动点击，把发送权死死捏在你手里。
- **零切换工作流**：省去“截图 -> 切网页 -> 复制 -> 粘贴”的繁琐折磨。
- **资深顾问视角**：不只生成话术，更帮你诊断 JD 核心诉求与匹配点。
- **BYOK 架构**：自己填 DeepSeek API Key，充几块钱用一整个求职季。
- **数据全本地**：档案与投递记录只存你的浏览器，绝不上传任何服务器。

## 🚀 安装与使用
1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. [点击这里前往 GreasyFork 安装脚本](【你的GreasyFork链接】)。
3. 打开 BOSS 直聘网页版，在右侧面板“我的档案”中配置你的 DeepSeek API Key 和简历。
4. 打开任意职位详情页，点击“一键生成招呼词”。
