# BOSS'boss · 求职招呼词生成助手

「当招聘方用AI筛选求职者，求职者值得拥有自己的AI——嵌入BOSS直聘的AI求职顾问，人工最后把关，零账号风险。」

## ⚠️ 必读：准备工作（BYOK 模式）
本工具属于“自带干粮”模式（BYOK - Bring Your Own Key），为了确保数据隐私并实现零服务器成本，**在使用前，你必须准备以下两样东西**：

1. **自备个人经历（个人档案）**：AI 只能根据你提供的事实来写话术，绝不瞎编。你需要把自己的基本信息、实习/项目经历、技能等，提前写进面板的“我的档案”里，作为 AI 生成的原材料。
2. **自备 DeepSeek API Key**：你需要去 DeepSeek 开放平台（[platform.deepseek.com](https://platform.deepseek.com/)）注册并生成一个 `sk-` 开头的 Key，充值几块钱即可用很久。没有 Key，脚本无法调用 AI。

## ✨ 核心特性
- **安全无风险**：绝不自动发送、绝不自动点击，把发送权死死捏在手里。
- **零切换工作流**：省去“截图 -> 切网页 -> 复制 -> 粘贴”的繁琐折磨。
- **资深顾问视角**：不只生成话术，更帮你诊断 JD 核心诉求与匹配点。
- **数据全本地**：你的档案、API Key 与投递记录只存你的浏览器，绝不上传任何第三方服务器。

## 🚀 安装与使用
1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. [点击这里前往 GreasyFork 安装脚本](https://greasyfork.org/zh-CN/scripts/601969-boss-boss)。
3. 打开 BOSS 直聘网页版，在右侧面板“我的档案”中配置你的 DeepSeek API Key 和简历。
4. 打开任意职位详情页，点击“一键生成招呼词”。
